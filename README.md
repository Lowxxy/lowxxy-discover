# Lowxxy Discover

Lowxxy discovery hub for vintage-inspired streetwear, graphic tees, animation, and interactive AR apparel.

## Publish with GitHub Pages

1. Upload all files in this folder to the root of the `lowxxy-discover` repository.
2. Go to **Settings > Pages**.
3. Set Source to **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

Expected URL:
https://lowxxy.github.io/lowxxy-discover/
